Technical writer resume keywords ATS actually looks for

Copywriter keywords (SEO, email, brand voice) will not save a documentation resume. Greenhouse and Workday match the words in the posting. Put the stack you really used in Skills and in one bullet per job — not in a keyword dump at the bottom.

High-signal terms from real TW postings

ClusterPut these on the resume if you used them
Structured authoringDITA, Darwin Information Typing Architecture, CCMS, information architecture, topic-based authoring
Docs-as-codedocs-as-code, Markdown, Git, GitHub, GitLab, Static Site Generator, Sphinx, MkDocs, Docusaurus, Vale
API / developer docsAPI documentation, OpenAPI, Swagger, REST, SDK, developer portal, code samples

Titles ATS searchesTechnical Writer, Documentation Engineer, Information Developer, Docs Engineer, Technical Publications

Do not list a tool you cannot defend on a screen-share. Recruiters who hire writers will ask you to open the CCMS or the docs repo.

How to write a bullet the parser and a hiring manager both keep

Weak: “Wrote user guides and helped the team.”

Strong: “Shipped DITA topics and OpenAPI-based API docs for a payments SDK; cut time-to-first-call by publishing runnable samples in the developer portal.”

The second line contains DITA, OpenAPI, API docs, SDK, and developer portal as natural English, which is what both Greenhouse keyword search and a docs manager want.

Remote search boolean LinkedIn will actually run

LinkedIn hides a lot of true work-from-anywhere documentation roles behind Easy Apply spam and US-only posts. Start with this, Remote filter on, past week:

("technical writer" OR "documentation engineer" OR "information developer" OR "docs engineer") AND (DITA OR "docs as code" OR "API docs" OR MadCap OR Oxygen)

Then open the company’s Greenhouse or Lever page. Many of the roles that never show in your LinkedIn feed live only there. Our job matcher builds that LinkedIn link and checks a short list of public Greenhouse boards.

US-only “remote” posts

If the posting says “must reside in the United States” or “authorized to work in the US,” skip it unless that is you. Location text is a filter, not a suggestion. The matcher drops those strings unless you choose Any location.
